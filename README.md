# HEFTOR — Pure Training Pro

Monorepo for the HEFTOR workout tracking app.

## Stack

| Layer | Tech |
|-------|------|
| Mobile | Flutter (iOS + Android) |
| Web | Next.js 14 (App Router, TypeScript, Tailwind) |
| Monorepo | Turborepo + npm workspaces |

## Design System

**Monochrome Performance** — extreme minimalism, pure black OLED background, white cards, Inter typeface, 8px grid.

## Apps

- `apps/web` — Next.js web dashboard
- `apps/mobile` — Flutter mobile app

## Getting Started

```bash
# Install dependencies
npm install

# Run web dev server
npm run dev

# Run Flutter app
cd apps/mobile && flutter run
```
